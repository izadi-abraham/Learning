# LeetCode Journey

Get better at problem solving by learning one pattern at a time.

**Rules**

- Think before reading solutions.
- Write the brute force first, then improve it.
- Revisit old problems.

## Layout

- `problems/` — one file per problem (`<number>-<slug>.md`); notes and code live together.
- `patterns/` — what each pattern taught me, with the problems that use it.
- `foundation/` — background CS notes (how a web request works, etc.).
- `TEMPLATE_PROBLEMS.md` / `TEMPLATE_PATTERNS.md` — starting points for new files.

## How I work

1. Copy `TEMPLATE_PROBLEMS.md` to `problems/<number>-<slug>.md` and solve it there.
2. Add a line to the log below.
3. Capture what the pattern taught me in `patterns/<pattern>.md` (start from `TEMPLATE_PATTERNS.md`).
